Finger telemetry

How to read these numbers 
Joint angle: the angle at the joint between its two neighbouring points.
  180° = straight finger, smaller = more bent.
3D: uses MediaPipe world landmarks (real-world scale, includes depth).
2D: flat image angle. It under-reads bending toward the camera,
  so compare the two columns to see depth at work.
MCP = knuckle (wrist, MCP, PIP). PIP = middle joint. DIP = near tip.
Heading: direction of the MCP-to-tip line as you see it on screen.
  0° = up, +90° = right, -90° = left, 180° = down.
Tip: fingertip position relative to the wrist in palm lengths
  (wrist to middle knuckle). x = right, y = up, as you see it.
  Hand size and camera distance cancel out.
Mirror view only changes the picture and the signs of heading and
Tip x. It never changes joint angles.
